## Project Overview  
**CEMS (Campus Event Management System)** is a web-based platform that allows **administrators, students, and lecturers** to create, manage, and participate in campus events such as **seminars, workshops, sports, and cultural activities**.  

The goal is to **digitalize campus event processes** — from announcements, registrations, to event reporting — providing a more efficient and centralized system. Containing 8 main modules.

---

## Lab 1 (Week 2): HTML Fundamentals  
This lab focuses on building the **basic structure** of the CEMS web system using **fundamental HTML elements**.
